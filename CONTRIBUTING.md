# Contributing to EverSquad

Thank you for helping keep AI accessible and free for everyone! You do not need to be a senior developer to contribute.

## Ways to Contribute
1. **Propose a New Free AI Agent:** Open an issue using the "Propose a Free AI Agent" template.
2. **Add an Agent via Pull Request:** Edit `registry/agents.json` and open a PR.
3. **Share a New Squad Recipe:** Edit `registry/squads.json` to combine agent roles into a workflow.

## Local Development
```bash
npm install
npm run dev
```
